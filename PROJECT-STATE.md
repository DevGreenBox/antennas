## Журнал решений

### 2026-10-05 — Чекпоинт 1: интервью и контракт данных

**Решения владельца (интервью):**
- Сейчас **только макет витрины**. Дальше — сращивание с **Admik** («другой платформы нет и не
  будет»), выкладка — **Vercel**. Бэкенд, БД, админка, интеграции — не в этом этапе.
- Покупатели — организации и частные лица (переключатель в заявке).
- Desktop-first.
- Вход в ЛК — код на email (в макете демо).

**Мои технические решения:**
- Стек как у прошлых макетов владельца (Electric_Fireplaces, noviy_mineral): Next 16.3 App Router,
  React 19, TypeScript strict, Tailwind v4, zustand (корзина/избранное/демо-заказы в localStorage),
  Playwright. Слой `src/lib/repository.ts` — точка будущей подмены на Storefront API Admik.
- Каталог генерируется скриптом из выгрузки Excel; ручные правки — в `src/data/overrides.json`.
- Временная витрина = лист 1 + уникальные позиции листа 2 (118 товаров из 132 строк);
  конфликтующие строки листа 2 сохраняются и показываются на служебной `/import-report`.
- Валюта RUB — предположение, деньги в копейках.
- Измерен цвет знака: **#FA9506** (99,69 % непрозрачных пикселей растра исходника).
  Контраст на белом ≈2,2:1 — не для текста.

**Состояние:** каркас проекта (package.json, tsconfig, next.config, eslint, prettier), контракт
`src/types/catalog.ts`, документы INTERVIEW и DATA-RULES. Запущен workflow «antennas-foundation»:
импорт + движок фильтров, перестройка логотипа, дизайн-система — с независимой проверкой.

**Точка восстановления:** если сессия прервалась — прочитать этот файл, `docs/INTERVIEW.md`,
`docs/DATA-RULES.md`; проверить наличие `src/data/*.generated.json`, `public/brand/logo-mark.svg`,
`docs/DESIGN.md`. Чего нет — тот трек не завершён.

### 2026-10-05 — Чекпоинт 3: данные, логотип и дизайн-система готовы и проверены

**Данные** (`npm run import:catalog`, `docs/IMPORT-REPORT.md`):

  8 рекомендаций (все `draft` — связи из названий прайса, ТЗ §7). Импорт идемпотентен (sha256).
- Независимая проверка: построчная сверка всех 146 записей против ручных ожиданий — 0 расхождений;
  ТЗ §4 п.1–16 выполнены; 7 minor-замечаний исправлены (счётчики «на проверку», типизированный
  разбор строк листа 2 в `SourceRecord.parsed`, статус рекомендаций, табличные тесты).

**Движок каталога** `src/lib/catalog/`: фильтры по группам категорий, частота (пересечение/

оранжевый только заливкой, текст бренда #9A5400; золотое сечение в колонках; 22 маршрута.

**Дальше:** фундамент UI (каркас, репозиторий, сторы и демо-заказы, UI-компоненты) → 4 агента

### 2026-10-05 — Чекпоинт 4: витрина собрана, e2e и независимое ревью

**Собрано:** фундамент UI (`docs/FRONTEND-API.md`) + 4 группы страниц — 22 маршрута + 404.
`npm run build` — 143 статические страницы (118 товаров SSG). tsc/lint/prettier — чисто;
`npm run test:unit` — 106/106.

**E2E (production-сборка, desktop + mobile):** 116 passed, 1 skipped (Drawer — только mobile),
1 failed — гонка: фокус в поиске шапки до гидратации не грузил индекс подсказок. Исправлено в
`SearchCombobox.tsx` (эффект при монтировании проверяет фокус).

**Независимое ревью (3 разреза):**
- ТЗ и честность данных: блокеров нет; 152 страницы и 175 внутренних ссылок без битых; значения
  листа 2 не утекают ни в HTML, ни в RSC, ни в индекс поиска; §14 по витрине выполнен. Major:
  снимок заказа в ЛК терял статусы значений («*», «Уточняется»).
- Код: major — открытый редирект `/login?next=/%09/evil`; битый localStorage ронял весь сайт
  (сбой в шапке корневого layout). 15 minor.
- Визуал/доступность: major — корзина и демо-панель на 1024; разные высоты ряда покупки;
  переносы внутри технических значений («N-» / «female»); невидимая кнопка в порядке Tab.

**Инцидент:** при остановке сервера ревью скан процессов по подстроке задел VS Code server —
сессия оборвалась. Правило в памяти: останавливать серверы только по слушающему порту
(`scratchpad/killport.py`).

**Сейчас:** 4 агента исправлений параллельно (покупка/ЛК; каталог/поиск; товар/главная;
каркас/SEO) против общего dev-сервера :3300. Дальше — сборка, полный e2e, повторная выборочная
проверка, обновление DESIGN, README, деплой на Vercel.
