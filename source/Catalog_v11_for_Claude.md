# Каталог из Excel для Claude Code

Источник: список v11(1).xlsx. Все непустые значения обоих листов сохранены. Данные не исправлялись и не объединялись.

## Правила чтения

- Колонки B/C, E/F и H/I листа 1 — независимые блоки. Совпадение номера строки не означает связь товаров.
- На листе 2 данные расположены в C/D.
- Заголовки и примечания не являются товарами. Названия листов не объясняют их назначение.
- Между листами есть отличия цен и характеристик. Не считать лист 2 устаревшим без подтверждения.
- «По запросу» не равно нулевой цене. Единицы, спорные значения и повторы сохранены буквально.
- Адрес ячейки позволяет сверить запись с исходным Excel.
